## 다른 대화창에서 갱신할 때

`Artifact` 도구에 `url` 로 위 주소를 넘겨야 같은 페이지가 갱신된다.
`url` 없이 배포하면 별개의 앱이 새로 생긴다.

- 배포 파일: `dist/index.html`
- favicon: 🏙️📰 (바꾸지 않는다 — 탭에서 이 아이콘으로 찾는다)
- title: 부동산 조간 브리핑
