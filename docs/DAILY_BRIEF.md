# 매일 아침 브리핑 절차

Claude가 매일 아침 이 순서대로 실행한다. 소요 시간 3~5분.

---

## 0. 준비

```bash
cd <estate-watch 폴더>
```

## 1. 청약홈 데이터 수집 (자동)

```bash
python scripts/fetch_apply.py
```

`data/apply.json` 이 갱신된다. 사람이 손댈 것 없음.

- 최근 분양결과 10개 — 경쟁률이 공개된 단지만, 접수 마감 최근순
- 청약 예정·접수중 10개 — 입주자모집공고가 나온 단지만
- 무순위·임의공급(줍줍)과 30세대 미만 잔여세대는 제외한다. 노이즈이기 때문.

## 2. 뉴스 후보 수집 (자동)

```bash
python scripts/fetch_news.py
```

`data/news_candidates.json` 에 한국경제·매일경제·연합뉴스 부동산 섹션 헤드라인 60여 건이 쌓인다.

## 3. 뉴스 5건 선별 + 요약 (Claude가 판단)

`data/news_candidates.json` 을 읽는다. 세 덩어리가 들어 있다.

- `candidates` — 고를 수 있는 것
- `excluded` — 이미 걸러낸 것과 그 사유 (버리지 않고 남겨 둔다)
- `recentPicks` — 최근 4일간 고른 제목. **여기 있는 사안은 다시 고르지 않는다**

### 어디서 오나

| 매체 | 강점 |
|---|---|
| 한국경제 · 매일경제 · 연합뉴스 | 정책·세제·시장 통계 |
| **네이버 지역뉴스** (서울·경기·인천) | **구·시 단위 개발 소식.** 역세권 개발, 지구단위계획, 추진위 승인처럼 종합지가 안 다루는 것 |

매경은 본문 추출이 막혀 있다. 제목만 참고하고 본문은 같은 사안의 다른 매체로 대체한다.

### 5건 고르는 기준

한 카테고리에 몰리지 않게 분산한다.

1. **정책·세제** — 종부세, 대출규제, 세제개편처럼 시장 전체를 움직이는 것
2. **공급·예산** — 국토부·서울시 공급계획, 예산, 택지지구, LH
3. **정비사업** — 재건축·재개발 제도 변화, 구역 지정, 조합 단계 진척, 시공사 선정
4. **개발·역세권** — 역세권 복합개발, 지구단위계획, 산단·MICE처럼 **일대 가치를 바꾸는 개발**
5. **시장지표** — 매매·전세·월세 가격, 거래량, 입주물량, 경쟁률 동향

### 빼는 것

- **분양단지 홍보 기사.** 모델하우스 개관, "○○ 분양 나선다", "주목받는 단지" 류.
  돈 받고 쓰는 기사라 판단 재료가 안 된다. 수집 단계에서 대부분 걸러지지만,
  걸러지지 않고 `candidates` 에 남은 것도 고르지 않는다.
  다만 **"9월 전국 2.2만가구 분양"** 같은 시장 통계는 홍보가 아니므로 쓴다.
- **회사 홍보·인사** — 대표 선임, 수상, 게시판.
- **최근 4일 안에 고른 사안** — `recentPicks` 와 겹치면 새 진전이 있을 때만 쓴다.
  (예: 어제 "종부세 유턴"을 썼다면, 오늘은 "그래서 얼마 줄었나" 같은 새 내용일 때만)

### 본문 가져오기

고른 5건은 반드시 추출기로 전문을 가져온다. WebFetch 는 작은 모델이 압축한 결과라
사실과 숫자가 빠진다.

```bash
python scripts/fetch_article.py <URL1> <URL2> ...
```

0문단이 나오면 그 매체 HTML 구조가 바뀐 것이다. 다른 기사로 대체하고 사용자에게 알린다.

### 쓰는 법

원문을 글자 그대로 복사하지 않는다(저작권). 대신 **사실·숫자·발언을 하나도 빠뜨리지 않고
문장만 다시 쓴다.** 원문이 15문단이면 `body` 도 10~13문단이 나와야 정상이다.

결과는 `data/news.json` 에 기존 형식 그대로 쓴다.

```json
{
  "date": "2026-09-02",
  "updatedAt": "2026-09-02T06:10:00+09:00",
  "editorNote": "오늘 시장을 꿰는 3~4문장. 개별 요약이 아니라 '무슨 일이 벌어졌나'.",
  "items": [
    {
      "rank": 1,
      "category": "세제·정책",
      "title": "기사 제목 그대로",
      "outlet": "연합뉴스",
      "publishedAt": "2026-09-02 13:00",
      "byline": "기자 이름",
      "summary": "제목 누르기 전에 보이는 한 줄. 기사의 결론.",
      "points": ["숫자가 들어간 핵심 5~7개"],
      "body": ["문단 단위. 원문 표현이 아니라 사실을 옮긴 요약문."],
      "url": "https://..."
    }
  ]
}
```

## 4. 빌드

```bash
python scripts/build.py
```

세 곳이 한 번에 갱신된다.

- `data/brief.json` — 안드로이드 앱이 받아가는 파일
- `android-app/app/src/main/assets/brief.json` — 앱 번들 스냅샷
- `dist/index.html` — 웹 페이지

## 5. 앱으로 전송

**안드로이드 앱** — `data/brief.json` 을 커밋해서 GitHub 에 올린다.

```bash
git add data/ dist/ android-app/app/src/main/assets/brief.json
git commit -m "9월 2일 브리핑"
git push
```

폰은 `master` 브랜치의 `data/brief.json` 을 그대로 읽는다.
**앱을 다시 빌드하거나 설치할 필요는 없다. 파일만 갈아끼우면 된다.**
(raw.githubusercontent.com 은 최대 5분 정도 캐시된다.)

**웹 페이지** — `dist/index.html` 을 **같은 Artifact URL로 재배포**한다.
URL은 `docs/ARTIFACT.md` 에 적혀 있다.

## 권한

**`~/.claude/settings.json` (사용자 전체)** 에서 자동 모드로 둔다.
프로젝트마다 따로 설정할 필요가 없고, 앞으로 만드는 루틴도 처음부터 자동으로 돈다.

```json
"permissions": {
  "defaultMode": "auto",
  "deny": ["Bash(git push --force*)", "Bash(git reset --hard*)",
           "Bash(rm -rf *)", "Read(**/.env)", ...]
}
```

명령 하나하나를 허용 목록으로 맞추는 방식은 **포기했다.** 실제로 나오는 모양이
`cd "..." && python ...`, `PYTHONIOENCODING=utf-8 python ...`, `... | tail -100`,
`python -c "..."` 처럼 끝없이 갈라져서 규칙이 못 따라간다.
2026-09-03 아침에 이것 때문에 15건 전부 요청이 떴다.

대신 **되돌릴 수 없는 것만 막는다** — `git push --force`, `git reset --hard`,
`git clean -fd`, `rm -rf`, 그리고 `.env`·개인키 읽기.
`.env` 차단은 카카오·네이버 키가 대화 기록에 남지 않게 하려는 것이다.
수집 스크립트는 파이썬 안에서 직접 읽으므로 영향받지 않는다.

프로젝트 `.claude/settings.json` 에는 그 프로젝트에만 해당하는 것만 둔다
(여기서는 `data/` 쓰기). 원래 설정은 `settings.backup-*.json` 으로 남겨 두었다.

> 자동 모드는 처음 한 번만 동의를 묻는다. 승인하면 다시 묻지 않는다.

## 확인 사항

빌드 후 아래가 맞는지 본다.

- 뉴스 5건, 분양결과 10건이 채워졌는가
- 분양결과의 `verdict`(1순위 전 타입 마감 / 일부 미달 / 1순위 미달)가 경쟁률과 어긋나지 않는가
- 청약예정이 3건 미만이면 그건 실제로 공고가 없는 것이다. 억지로 채우지 않는다.

## 수집이 실패하면

`scripts/fetch_apply.py` 가 0건을 뱉으면 원본 사이트 구조가 바뀐 것이다.
그날은 [청약홈 APT 분양정보](https://www.applyhome.co.kr/ai/aia/selectAPTLttotPblancListView.do)를 직접 열어
손으로 `data/apply.json` 을 채우고, 파서는 따로 고친다.
